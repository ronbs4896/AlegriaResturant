# פונטים · Fonts

חלוקת העבודה בין הפונטים:

- **Rubik** (`Rubik-Variable-*.woff2`, וריאבילי 300–900) — עברית,
  ספרות ו-₪. ההגבלה נעשית ב-`unicode-range` בהצהרות ה-@font-face
  שב-`src/index.css`: הקובץ העברי מגיש את העברית, והקובץ הלטיני
  מגיש **ספרות בלבד** (האותיות הלטיניות שבו מחוץ לטווח ולכן לא
  בשימוש).
- **Birzia** (4 משקלים, woff2+woff) — כל מה שמחוץ לטווח של Rubik,
  בעיקר טקסט באנגלית. נשאר בכוונה.

## איך מחליפים את הפונט העברי
1. להניח כאן קובץ `.woff2` (וריאבילי עדיף; אם יש רק ttf/otf — להמיר).
2. לעדכן את שתי הצהרות ה-@font-face ב-`src/index.css` ואת
   `fontFamily` ב-`tailwind.config.js`.
3. לעדכן את שורות ה-preload ב-`index.html`.

הערה: קובצי ה-`.otf` של Birzia שמורים כאן כגיבוי מקור בלבד —
אף הצהרה לא מפנה אליהם.
